# Alternative Comparison

| Property                       | ALT-01 BugHunt                                                                                 | ALT-02 Codewars                                                                                                          | ALT-03 Microsoft debug-gym                                                                                                   |
| ------------------------------ | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| **Debugging realism**          | Strong: starts from existing code + symptom and asks the user to locate the bug (ALT-01).      | Medium: has dedicated bug-fixing kata, but debugging is one category within a broader coding-practice platform (ALT-02). | Strong: supports repository-level debugging tasks and failing-test scenarios (ALT-03).                                       |
| **Investigation support**      | Editor, test execution, and step-through visualizer with variable values (ALT-01).             | Editor, sample tests, output, hidden full tests, and custom sample tests (ALT-02).                                       | Rich interactive toolkit including `pdb`, `bash`, `grep`, `view`, `eval`, and `edit` (ALT-03).                               |
| **Feedback & guidance**        | Three progressive hints + post-solution bug-pattern explanation + reference solution (ALT-01). | Test output + access to other users' solutions after completion/forfeit (ALT-02).                                        | Tool observations and test results, but primarily designed for agent interaction rather than pedagogical feedback (ALT-03).  |
| **AI assistance**              | No AI assistant observed in the evaluated public flow (ALT-01).                                | No AI debugging assistant observed in the evaluated trainer (ALT-02).                                                    | AI agents are a central part of the framework and interact with debugging tools (ALT-03).                                    |
| **Task variety & difficulty**  | Python and JavaScript; multiple bug patterns and difficulty levels (ALT-01).                   | Large multi-language kata ecosystem with ranked difficulty and dedicated debugging kata (ALT-02).                        | Supports multiple benchmarks and custom buggy snippets, but the current focus is repository-level Python debugging (ALT-03). |
| **Onboarding**                 | Very low: browser-based, no installation or account required to start (ALT-01).                | Low: select a kata and use the browser-based trainer (ALT-02).                                                           | High: Python 3.12, package installation, LLM configuration, and terminal/environment setup required (ALT-03).                |
| **Extensibility / deployment** | Hosted browser product; no obvious custom/self-hosted challenge workflow observed (ALT-01).    | Users can author kata with custom code and tests, but authoring has platform requirements (ALT-02).                      | High: custom tools, agents, benchmarks, LLM backends and Docker/Kubernetes environments are supported (ALT-03).              |
