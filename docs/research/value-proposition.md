# Value Proposition

These are draft propositions to validate, not confirmed product commitments. They are informed by the gaps in [`gap-analysis.md`](gap-analysis.md).

## VP-01: Practice debugging in realistic code

**Draft:** Debug GYM helps learners practice investigating and fixing bugs in realistic code, with tasks that can grow beyond isolated snippets.

**Traceability:** GAP-01; ALT-01, ALT-02, ALT-03.

**Rests on:** [ASM-01](../assumptions.md#asm-01),
[ASM-02](../assumptions.md#asm-02), and
[ASM-03](../assumptions.md#asm-03).

**Validation:** Ask learners to compare a snippet-based task with a small multi-file task and describe which better supports their goals.

## VP-02: Learn a repeatable investigation process

**Draft:** Debug GYM helps learners build debugging habits by offering optional, staged guidance and feedback about their investigation as well as their final fix.

**Traceability:** GAP-02, GAP-03; ALT-01, ALT-02, ALT-03.

**Rests on:** [ASM-04](../assumptions.md#asm-04),
[ASM-05](../assumptions.md#asm-05), and
[ASM-06](../assumptions.md#asm-06).

**Validation:** Test optional hint levels and ask learners whether the guidance changed their reasoning or merely revealed the answer.

## VP-03: Start quickly, then access useful tools

**Draft:** Debug GYM makes it straightforward to begin a debugging task while providing investigation tools as task complexity increases.

**Traceability:** GAP-04; ALT-01, ALT-02, ALT-03.

**Rests on:** [ASM-07](../assumptions.md#asm-07) and
[ASM-08](../assumptions.md#asm-08).

**Validation:** Observe learners starting a first task and record where they need help or abandon the flow.
