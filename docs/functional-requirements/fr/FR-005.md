# FR-005: Debug With VS Code Tools

- **Status:** Active
- **Traces to:** [`US-05`](https://github.com/team-ok-ITPD/team-OK-itpd/issues/32), [`DEC-007`](../../decisions.md#dec-007), [`CON-02`](../../product-vision.md#con-02)
- **Containers:** `debug workspace`

## Behavior

When a learner connects from VS Code to a prepared environment over remote SSH with valid access, the product shall let the learner set a breakpoint and run the reproduction tests under the debugger.

When a learner attempts to connect without valid access, the product shall refuse the connection.

## Acceptance Criteria

### AC-01

Given valid remote SSH access to the prepared workspace, when the learner selects `Debug reproduction tests`, sets a breakpoint in `remove_negatives.py`, and starts debugging from VS Code, then execution stops at that breakpoint before the failing test finishes.

### AC-02

Given invalid remote SSH credentials, when a learner attempts to connect to the prepared environment from VS Code, then the connection is refused and no exercise files are exposed.
