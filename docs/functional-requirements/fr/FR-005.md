# FR-005: Debug With VS Code Tools

- **Status:** Active
- **Traces to:** [`US-05`](https://github.com/team-ok-ITPD/team-OK-itpd/issues/32), [`DEC-007`](../../decisions.md#dec-007), [`CON-02`](../../product-vision.md#con-02)
- **Containers:** `debug workspace`

## Behavior

When a learner opens a prepared exercise through the deployment's approved VS Code access path, the product shall let the learner set a breakpoint and run the reproduction tests under the debugger.

When a connection does not meet the deployment's access boundary, the product shall refuse the connection.

## Acceptance Criteria

### AC-01

Given the prepared workspace, when the learner selects `Debug reproduction tests`, sets a breakpoint in `remove_negatives.py`, and starts debugging, then execution stops at that breakpoint before the failing test finishes.

### AC-02

Given the learner-local pilot deployment, when a device outside the learner's computer attempts to connect through its network interface, then neither the catalog nor the workspace accepts the connection.
