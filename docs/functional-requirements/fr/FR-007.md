# FR-007: Browse Bug Categories With Examples

- **Status:** Active
- **Traces to:** [`US-07`](https://github.com/team-ok-ITPD/team-OK-itpd/issues/34), [`GAP-01`](../../research/gap-analysis.md#gap-01), [`ADR-001`](../../architecture/adr/ADR-001.md)
- **Containers:** `exercise catalog`

## Behavior

When a learner opens the available bug categories, the product shall display at least one example for each category it offers.

When the learner selects an offered category, the product shall allow the learner to request an exercise belonging to that category.

## Acceptance Criteria

### AC-01

Given the set of categories offered by the product, when the category list is opened, then every category has a non-empty example illustrating that category.

### AC-02

Given an offered category with an available exercise, when the learner selects it and requests an exercise, then the returned exercise belongs to the selected category.

The baseline text-query page does not implement category browsing. This requirement chooses neither a menu layout nor a number of categories.
