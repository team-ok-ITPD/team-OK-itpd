# FR-014: Record An Event For Each Core-Task Step

- **Status:** Active
- **Traces to:** [`VP-01`](../../research/value-proposition.md#vp-01), [`ADR-006`](../../architecture/adr/ADR-006.md), [`FR-011`](FR-011.md)
- **Containers:** `exercise catalog`

## Behavior

When a learner searches the prepared exercises, opens an exercise, opens its workspace or has a submitted solution verified, the product shall record the matching event from [The Events](../../analytics.md#the-events) with the fields that table lists.

The product shall give every event a `source` from the closed set `web`, `usability-test` and `smoke`, and an opaque `learner_id` that is generated at random, is not derived from personal data and cannot be reversed to the learner. An event shall carry no name, email address or free text.

The product shall record `solution_verified` from the server's verification result ([FR-011](FR-011.md)), never from counts reported by the browser or the VS Code extension.

When event collection is not configured or the analytics backend cannot be reached, the product shall serve the request as it otherwise would.

## Acceptance Criteria

### AC-01

Given a signed-in learner, when the learner searches, opens an exercise, opens its workspace and submits a solution, then one event of each of `exercise_searched`, `exercise_opened`, `workspace_opened` and `solution_verified` is sent with the fields in `docs/analytics.md#the-events`.

### AC-02

Given any recorded event, then it carries a `source` from the closed set and a `learner_id` that equals neither the learner's username nor email, and it carries no other personal field.

### AC-03

Given a submission whose client claims all tests pass, when it is verified, then `solution_verified` carries the container's `passed_count`, `total_count` and `all_passed`.

### AC-04

Given collection is not configured, or the backend is unreachable, when a learner searches, then the response is the same as with collection working.

## Open points

The catalog now emits the specified events when an HTTPS backend URL is
configured. The target OpenPanel deployment and separate staging and production
credentials have not been provisioned or verified.
