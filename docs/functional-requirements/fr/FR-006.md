# FR-006: Assist Without Editing The Learner's Code

- **Status:** Active
- **Traces to:** [`US-06`](https://github.com/team-ok-ITPD/team-OK-itpd/issues/33), [`DEC-004`](../../decisions.md#dec-004), [`BND-01`](../../product-vision.md#bnd-01), [`ADR-001`](../../architecture/adr/ADR-001.md)
- **Containers:** `debug workspace`

## Behavior

When a learner requests assistance while investigating an exercise in VS Code, the product shall display the assistance in VS Code.

When assistance is requested or displayed, the product shall leave the learner's source files unchanged until the learner edits them.

## Acceptance Criteria

### AC-01

Given an open exercise in VS Code, when the learner requests assistance, then an assistance response appears in that same VS Code workspace.

### AC-02

Given recorded source-file contents before the request, when the assistance response appears without the learner editing a file, then every source file has the same contents as before the request.

The baseline has no assistance integration. Explanation, hint and solution-reveal levels remain a Customer question; this requirement chooses neither an assistance policy nor an AI provider.
