# FR-012: Submit From VS Code Without Signing In Again

- **Status:** Active
- **Traces to:** [`DEC-028`](../../decisions.md#dec-028), [`DEC-031`](../../decisions.md#dec-031), [`DEC-038`](../../decisions.md#dec-038), [`FR-004`](FR-004.md), [`ADR-003`](../../architecture/adr/ADR-003.md)
- **Containers:** `exercise catalog, debug workspace`

## Behavior

When a learner opens an exercise's workspace, the product shall give the VS Code folder a per-user, per-exercise connection key and store only its hash.

When the VS Code extension submits with that key, the product shall attribute the attempt to the key's learner and exercise, save the submitted code as the learner's draft, and let the exercise page show the new result.

The product shall reject a missing or unknown key with `401`, a key for another exercise with `400`, and a key whose learner can no longer open the exercise with `403`, deleting that key.

## Acceptance Criteria

### AC-01

Given a connected folder, when the extension submits code, then an attempt and a draft for that learner and exercise exist.

### AC-02

Given a request with no valid key, then the response status is `401` and nothing is saved.

### AC-03

Given a key whose learner lost access to the exercise, when it submits, then the response status is `403` and the key no longer works.
