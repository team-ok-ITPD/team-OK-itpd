# FR-001: Match A Prepared Exercise

- **Status:** Active
- **Traces to:** [`US-01`](https://github.com/team-ok-ITPD/team-OK-itpd/issues/28), [`DEC-008`](../../decisions.md#dec-008), [`CON-01`](../../product-vision.md#con-01), [`ADR-001`](../../architecture/adr/ADR-001.md)
- **Containers:** `exercise catalog`

## Behavior

When a learner submits a plain-language request that names Python and a supported bug category, the product shall return the matching prepared exercise with its title, problem statement, and workspace link.

When a learner submits a request for which no prepared exercise exists, the product shall report that no exercise is available and shall not create or return a workspace.

## Acceptance Criteria

### AC-01

Given the request `I want a Python list mutation bug`, when the catalog receives it, then the response identifies the `remove-negatives` exercise and includes its workspace link.

### AC-02

Given the request `I want a Python concurrency bug`, when the catalog receives it, then the response has status `404`, explains that no prepared exercise matches, contains no exercise object or workspace link, and creates no learner workspace.

### AC-03

Given `A Python loop off-by-one bug` or `A Python list concurrency bug` and no exercise of that type in the available catalog, when the request is submitted, then the product reports no matching exercise rather than returning the list-mutation exercise merely because a keyword overlaps.
