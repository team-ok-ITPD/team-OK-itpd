# FR-003: Reproduce The Intended Bug

- **Status:** Active
- **Traces to:** [`US-03`](https://github.com/team-ok-ITPD/team-OK-itpd/issues/30), [`DEC-006`](../../decisions.md#dec-006), [`ADR-001`](../../architecture/adr/ADR-001.md), [`ADR-002`](../../architecture/adr/ADR-002.md)
- **Containers:** `debug workspace`

## Behavior

When a learner runs the documented reproduction command against an unchanged exercise, the product shall execute the exercise tests and show the failures caused by the intended bug.

When the learner repeats the command without changing the exercise, the product shall show the same failing tests.

## Acceptance Criteria

### AC-01

Given the unchanged `remove-negatives` exercise, when `python -m pytest -q` is run twice, then both runs exit with status `1` and name `test_mixed_numbers` and `test_consecutive_negatives` as failures.
