# FR-004: Verify A Learner's Fix

- **Status:** Active
- **Traces to:** [`US-04`](https://github.com/team-ok-ITPD/team-OK-itpd/issues/31), [`DEC-006`](../../decisions.md#dec-006), [`DEC-010`](../../decisions.md#dec-010)
- **Containers:** `debug workspace`

## Behavior

When a learner runs verification, the product shall show the complete test output and shall report a failure while the intended bug remains or a pass after the learner fixes it.

## Acceptance Criteria

### AC-01

Given the unchanged `remove-negatives` implementation, when `python -m pytest -q` is run, then it exits with status `1` and its output names `test_mixed_numbers` and `test_consecutive_negatives` as failures.

### AC-02

Given the reference implementation in place of the buggy implementation, when `python -m pytest -q` is run against the same tests, then it exits with status `0` and reports three passing tests.
