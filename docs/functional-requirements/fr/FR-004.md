# FR-004: Verify A Learner's Fix

- **Status:** Active
- **Traces to:** [`US-04`](https://github.com/team-ok-ITPD/team-OK-itpd/issues/31), [`DEC-006`](../../decisions.md#dec-006), [`DEC-010`](../../decisions.md#dec-010)
- **Containers:** `debug workspace`

## Behavior

When a learner runs verification after changing the exercise, the product shall show the complete test output and shall report whether the changed implementation passes every exercise test.

## Acceptance Criteria

### AC-01

Given a changed implementation that still leaves a negative value in the result, when `python -m pytest -q` is run, then it exits with status `1` and its output names the failing test.

### AC-02

Given the reference implementation in place of the buggy implementation, when `python -m pytest -q` is run against the same tests, then it exits with status `0` and reports three passing tests.
