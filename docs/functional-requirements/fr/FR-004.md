# FR-004: Verify A Learner's Fix

- **Status:** Active
- **Traces to:** [`US-04`](https://github.com/team-ok-ITPD/team-OK-itpd/issues/31), [`DEC-006`](../../decisions.md#dec-006), [`DEC-010`](../../decisions.md#dec-010)
- **Containers:** `debug workspace`

## Behavior

When a learner runs verification while the intended bug remains, the product shall report a failure and show the complete output with at least one failing test name.

When a learner runs verification after applying a correct fix, the product shall report that all exercise tests pass.

## Acceptance Criteria

### AC-01

Given the unchanged `remove-negatives` implementation, when `python -m pytest -q` is run, then it exits with status `1` and its output names at least one failing test.

### AC-02

Given the reference implementation in place of the buggy implementation, when `python -m pytest -q` is run against the same tests, then it exits with status `0` and reports three passing tests.
