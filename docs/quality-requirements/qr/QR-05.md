# QR-05: A Learner Can Reset The Exercise

A learner who has changed or broken the exercise can restore the original buggy version within two minutes, and it fails the same tests as before.

- **Status:** Active
- **Characteristic:** Reliability
- **Sub-characteristic:** Recoverability
- **Business importance:** Medium
- **Technical risk:** Low

## Scenario

### Source

A learner who wants to try the exercise again from the start.

### Stimulus

The learner follows the documented reset after saving changes to the exercise.

### Environment

The workspace is running with edited exercise files, on a learner's own computer.

### Artifact

The exercise files in the prepared workspace and the reset described in `exercise/README.md`.

### Response

The workspace shall return to the original buggy exercise, so the learner can reproduce the failure again.

### Response Measure

Within two minutes of starting the documented reset, `python -m pytest -q` in the exercise reports the same failing tests, `test_mixed_numbers` and `test_consecutive_negatives`, as on the first run.

Reset is destructive to the selected workspace volume; the two-minute bound is a target, not an assertion of a timed run on every operating system.
