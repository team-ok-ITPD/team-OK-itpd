# QR-01: Exercises Contain The Requested Bug

Each exercise contains the bug it promises, and its tests fail on the buggy program and pass on the correct one.

- **Status:** Active
- **Characteristic:** Functional Suitability
- **Sub-characteristic:** Functional Correctness
- **Business importance:** High
- **Technical risk:** High

## Scenario

### Source

An exercise author, or the validation run the team repeats before a release, checks an exercise a learner could be given.

### Stimulus

An exercise is sampled and its buggy program, its reference solution and its tests are run.

### Environment

Normal operation, with the pinned Python and test dependencies of the product's container, and a library of at least ten exercises, as [`TOS-02`](../../threshold-of-success.md#tos-02) assumes.

### Artifact

An exercise: its buggy program, its reference solution and its tests, such as `exercise/remove_negatives.py`, `exercise_author/correct_remove_negatives.py` and `exercise/tests/test_remove_negatives.py`.

### Response

The tests shall fail on the buggy program, naming the failing cases that show the intended defect, and shall pass on the reference solution.

### Response Measure

In a validation run over ten sampled exercises, at least nine fail on the buggy program for the intended defect and pass on the reference solution, and the run can be repeated with the same result.

The ten-exercise scenario is a later library target; the baseline has one curated exercise, not a ten-exercise validation result.

## QRT-01

The curated exercise fails for the intended defect and passes with its reference solution.

- **Status:** Active
- **Level:** CI
- **Runs at:** the `test` job's `Automated tests - catalog and exercise contract` step in `.github/workflows/product.yml`, on every pull request and on `main`.

### Procedure

1. From a clean checkout, let the product workflow install the pinned dependencies.
2. Run `python -m pytest` through the `Automated tests - catalog and exercise contract` step.
3. Read the result of `test_pytest_reproduces_bug_and_accepts_reference_solution`.

**Pass when:** the curated buggy program fails for the named intended cases, its reference solution passes the same tests, and the CI step exits with status 0.
