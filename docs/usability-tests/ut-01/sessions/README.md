# UT-01 Session Template

1. Welcome the participant, explain that the product is being tested, not them, and remind them they may stop at any time.
2. Confirm completed consent, age declaration and recording permission before starting any recording.
3. Collect the pre-test privately and assign the next `P-nn` code.
4. Ask the participant to think aloud: say what they expect, notice and decide; silence is acceptable.
5. Read each scenario exactly, start the timer, observe without help, record outcome/help/time/friction, then ask the SEQ question.
6. After Task 3, collect SUS and open post-test answers privately.
7. Debrief, explain the next steps, and confirm withdrawal contact information.

For each task record: code, UTC start/end, task outcome, help given, time, SEQ, observed friction and event-window match. Stop and do not count the session on withdrawal, refused recording, missing consent or a material technical failure.
