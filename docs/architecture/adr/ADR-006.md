# ADR-006: Send Analytics Events From The Catalog To An External Backend

- **Status:** Proposed
- **Created:** 2026-11-08
- **Updated:** 2026-11-08
- **Containers:** `exercise catalog`
- **Addresses:** [`FR-014`](../../functional-requirements/fr/FR-014.md), [`QR-02`](../../quality-requirements/qr/QR-02.md), [`QR-04`](../../quality-requirements/qr/QR-04.md)

## Context

The [analytics plan](../../analytics.md) reads the product's value from events such as `solution_verified`. A solved exercise is decided by the server's verification ([ADR-004](ADR-004.md)), and learners must not be identifiable from the events. The product emits searches, exercise opens, workspace opens and verification results when an analytics backend is configured; its database remains responsible only for product state.

## Considered Options

- Track in the browser with an analytics script: rejected because a client can forge or block events, and a third-party script sees learner pages.
- Derive metrics from the product's own database: rejected because searches and opens are not stored, and dashboard queries would run against the database that serves learners.
- Send events from the catalog server to an external, self-hosted analytics backend: chosen.

## Decision Outcome

The `exercise catalog` emits each event server-side over HTTPS from a bounded background queue to an OpenPanel instance that the team self-hosts and does not build. The backend is outside the product boundary and the product works with collection off. Each environment has its own project and credential. The instrumentation is implemented; the OpenPanel instance and its projects are not deployed yet.

## Consequences

- Events reflect what the server observed, and `learner_id` is opaque, supporting [QR-02](../../quality-requirements/qr/QR-02.md) on privacy.
- Emission adds work to request handling, so it must be bounded and must not fail a request, protecting the search time target in [QR-04](../../quality-requirements/qr/QR-04.md).
- The team operates one more service per environment and must keep its credentials out of the repository.
