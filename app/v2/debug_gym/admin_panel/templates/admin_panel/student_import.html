CSV format

UTF-8, comma-separated, at most 1 MB / 5000 rows. Required headers: name,email. Optional: is_active,password,course,group_number,teacher_email. One row per student/group; repeat identical account data for multiple groups.

name,email,is_active,password,course,group_number,teacher_email
Example Student,student@example.com,true,,Programming,01,teacher@example.com

A new group needs a course name, a separate group number and an existing active teacher. The same course can have several numbered groups. Existing teachers are never reassigned by import. Specify group_number when a course has several groups.

Existing students are matched by email ignoring case. Blank password/status preserves the existing value. New students need a password of at least 8 characters unless access email is configured. Passwords are stored only as hashes. Blank course and group number creates/updates the student without enrollment. Omitted groups are never removed.

Repeating identical data creates no duplicates. All rows are validated in a transaction: any error rolls back the entire file. CSV contents and passwords are not logged or stored as uploaded files.
