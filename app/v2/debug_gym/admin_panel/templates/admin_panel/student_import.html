CSV format

UTF-8, comma-separated, at most 1 MB / 5000 rows. Required headers: name,email. Optional: is_active,course,teacher_email. One row per student/group; repeat identical account data for multiple groups.

name,email,is_active,course,teacher_email
Example Student,student@example.com,true,Programming A,teacher@example.com

The course column identifies the group by name. A new group needs a name and an existing active teacher. Existing teachers are never reassigned by import.

Existing students are matched by email ignoring case. Blank status preserves the existing value. New active students receive an email invitation to choose their password when email delivery is enabled. Otherwise, configure email and send an access link later. A legacy password column is accepted but ignored; existing passwords never change during import. Blank course creates/updates the student without enrollment. Omitted groups are never removed.

Repeating identical data creates no duplicates. All rows are validated in a transaction: any error rolls back the entire file. CSV contents and passwords are not logged or stored as uploaded files.
