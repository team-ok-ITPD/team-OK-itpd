Project plan

Milestones

MLS-03

  • Due: 2026-10-17
  • Sprints: SPRINT-03
  • Advances: TOS-01

A learner can choose a prepared Python bug, open a ready VS Code environment, reproduce the failure, debug it, and verify the fix. The increment includes one curated exercise and the setup evidence needed to run the flow from a clean checkout.
