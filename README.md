# Debug GYM

Team 02

Debug GYM is a project focused on designing and developing a practical, interactive platform for improving debugging skills through realistic software-engineering challenges and guided practice.

## Overview

Modern software development depends not only on writing code, but also on diagnosing and fixing defects efficiently. Debug GYM aims to provide a structured environment where learners and developers can strengthen their debugging workflows through realistic tasks, feedback, and progressive learning experiences.

This repository currently captures the project’s research, candidate analysis, and early design direction as part of the ITPD course workflow.

## Project Goals

- Explore existing debugging training and evaluation platforms
- Identify useful patterns from current tools and research
- Define a clear value proposition for a debugging-focused learning environment
- Structure the project around realistic debugging tasks and workflow practice
- Build a foundation for future implementation and iteration

## Why Debug GYM?

Software debugging is a critical skill, yet many learning resources focus on coding rather than the process of finding and fixing real defects. Debug GYM addresses this gap by emphasizing:

- realistic debugging scenarios
- structured problem-solving workflows
- progressive difficulty levels
- practice grounded in software-engineering contexts
- support for learning through iteration and feedback
