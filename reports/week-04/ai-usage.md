# Week 4 AI Usage

## Codex

Codex inspected the existing stories, decisions, local implementation and course requirements, and consolidated the team's FR and ADR drafts into the A4 specification package. It drafted the glossary, repository agent instructions, navigation and a previewable issue-conversion tool. This entry covers this contribution only, not every team member's AI usage.

SSH and invalid-access requirements are preserved. This work does not claim Customer acceptance, an Ubuntu rehearsal, implemented assistance, submission tracking or shared-service isolation. Accepted ADRs document existing technical choices, not proof that every addressed requirement passes.

Generated content needs team review against source evidence and PR checks. Issue conversion defaults to a local preview and refuses to apply links to specification files not yet on `main`; a preview does not mean the live conversion is complete.
